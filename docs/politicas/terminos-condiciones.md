# Términos y Condiciones de Uso de SalesStock Pro

Al acceder y utilizar SalesStock Pro, usted acepta estar vinculado por estos Términos y Condiciones. Si no está de acuerdo con alguna parte de estos términos, no utilize el servicio.

## 2. Descripción del servicio

SalesStock Pro es un sistema de gestión de ventas e inventario que permite:
- Administrar productos y stock
- Realizar ventas y generar facturas
- Gestionar créditos y fiados
- Administrar usuarios por empresa
- Generar reportes y análisis

## 4. Uso aceptable

- Uso del sistema para gestión comercial legítima

- Generación de reportes para toma de decisiones

### 4.2 Prohibido
